@main.py
---------
High-level controller script. Does NOT need to import pipeline.py.

Functions:
  - process_all_files(): Load and structure raw files
  - train_pipeline(): Train the classifier using training data
  - validate_pipeline(): Run predictions on validation set and evaluate performance
  - make_predictions(): Run final predictions on test set


#1 — Load and Structure Input Data
==================================

@ProteinDataProcessor.py
-------------------------
Processes raw input files into structured dictionaries used throughout the project.

Processing Raw Files:
  - process_train_tsv()
      • Input: train.tsv
      • Output: 
          - train_df (pandas DataFrame)
          - train_tsv_dict: { protein_name → list of secondary structure labels }
      • Notes: Pads the label list to match residue indices.

  - process_test_tsv()
      • Input: test.tsv
      • Output: 
          - test_df (pandas DataFrame)
          - test_tsv_dict: { protein_name → list of residue IDs }

  - process_sequences_fasta()
      • Input: sequences.fasta
      • Output: 
          - raw_sequences_dict: { protein_name → full amino acid sequence (string) }

Filtering:
  - filter_training_sequences()
      • Keeps proteins where sequence length ≥ label length (from train.tsv)

  - filter_testing_sequences()
      • Keeps proteins that are present in test_tsv_dict

  - make_training_validation_sets()
      • Splits training_sequences_dict into training_set and validation_set (every 5th protein goes to validation)

  - make_testing_set()
      • Filters valid test sequences and stores in testing_set

Structured Data:
  - train_tsv_dict            → { protein → list of secondary structures }
  - test_tsv_dict             → { protein → list of residue IDs }
  - raw_sequences_dict        → { protein → sequence string }
  - training_sequences_dict   → { protein → sequence string (filtered) }
  - testing_sequences_dict    → { protein → sequence string (filtered) }
  - training_set              → { protein → (sequence, structure list) }
  - validation_set            → { protein → (sequence, structure list) }
  - testing_set               → { protein → sequence string }

Note:
** If a sequence in the FASTA file is shorter than the final residue index in train/test.tsv,
   it must be filtered out — otherwise the prediction tensor won't align. 
   In postprocessing, fill in placeholder `.` for residues with no prediction (i.e. out of bounds).


#2 — Train the Classifier and Predict
=====================================

@ProteinPredictionPipeline.py
------------------------------
Pipeline utilities for feature extraction, classification, and postprocessing.

(1) Embedding:
  - tokenize_and_embed(sequence)
      • Input: raw amino acid sequence (string)
      • Output: embedding tensor from ESM (logits)

(3) Classification:
  - predict_secondary_structure(sequence)
      • Input: raw amino acid sequence
      • Output: list of predicted secondary structure labels (per residue)

(4) Postprocessing:
  - align_predictions_to_ids()
      • Ensures output aligns with expected residue IDs
      • Adds '.' placeholders for missing positions or padding


@trainer.py
-----------
(2) Training the Classifier:
  - generate_logits()
      • Input: dictionary { protein → sequence }
      • Output: dictionary { protein → embedding tensor }

  - train_classifier()
      • Uses ESM embeddings + secondary structure labels to train a Random Forest classifier


#3 — Validate Performance
==========================

@validator.py
-------------
Runs predictions on validation set and evaluates accuracy.

  - validate()
      • Uses same pipeline as test predictions
      • Compares predicted labels to true labels
      • Outputs accuracy and possibly confusion matrix


#4 — Generate Final Predictions on Test Set
===========================================

@feeder.py
----------
Runs the trained model on unseen test data and formats predictions for submission.

  - run_test_pipeline()
      • Uses trained model + ESM embeddings
      • Outputs formatted CSV for Codabench upload

TOKENIZE AND EMBED - Autotokenizer. AutoModel.from_pretrained(checkpoint), checkpoint = "esm..."
- tokenizer: convert each input into a list of tokens
- embedder: generate embeddings from tokens and extract last hidden state: logits (learned embeddings)
PREDICT
- from logits, apply softmax layer to normalize (sum to 1)
- from normalized logits (aka best embeddings), make predictions/labels/outputs, use model.config.id2label
